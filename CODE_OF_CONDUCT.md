# Code of conduct

## Standard

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

## Expected behaviour

Be direct about technical disagreement and considerate about people. Review the change,
not the contributor. Assume the other person read the constraint and reached a different
conclusion, then ask which constraint they weighted differently.

## Unacceptable behaviour

Harassment, personal attacks, publishing private information, and sustained disruption of
technical discussion.

## Enforcement

Report conduct concerns to the repository owner through GitHub. Reports are handled
privately. Consequences range from a warning to a permanent ban, in proportion to the
behaviour and any pattern behind it.
